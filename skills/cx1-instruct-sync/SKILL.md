# 同步个人指令

仅在用户明确调用本技能时执行。调用即授权按仓库规则提交并推送个人指令变更。

1. 解析 `${CODEX_HOME:-$HOME/.codex}/AGENTS.md` 的符号链接，以目标文件所属的 Git 仓库为同步仓库。若无法定位，询问仓库位置，不猜测或重新初始化。
2. 阅读仓库的 `README.md` 和适用的 `AGENTS.md`，按仓库内的同步规则执行。文件范围、路径映射、远端和分支信息以仓库文档及 Git 配置为准，不在本技能维护文件清单。缺少同步规则时先说明缺失项，不盲目推送。
3. 报告同步结果、提交及剩余未同步变更；无变更且无待推送提交时直接说明已同步。

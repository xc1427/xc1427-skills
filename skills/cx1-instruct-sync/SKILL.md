# 同步个人指令

仅在用户明确调用本技能时执行。仓库约定只在目标仓库维护，本技能不重复定义。

1. 解析 `${CODEX_HOME:-$HOME/.codex}/AGENTS.md` 的符号链接，以目标文件所属的 Git 仓库为同步仓库。若无法定位，询问仓库位置，不猜测或重新初始化。
2. 阅读仓库的 `README.md` 和适用的 `AGENTS.md`，取得同步范围、授权边界、目标和停止条件。按其中的映射与部署说明核对消费路径。缺少必要约定时说明缺失项，不猜测。
3. 检查本地变更和远端状态，按仓库约定审阅、提交并推送；遵守适用指令中的 Git 身份和提交归属要求。没有新变更时只推送已有的范围内提交；也没有待推送提交时，直接说明已同步。
4. 核对远端分支与本地 HEAD 一致，报告提交链接及剩余未同步变更。区分 Git 发布、链接部署和实际会话加载；只报告已验证的结果。失败时说明原因和保留的本地状态。
